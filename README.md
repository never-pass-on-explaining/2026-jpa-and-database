# JPA & Database

### 스터디 개요

인원 : 6
기간 : 2026.09.05 ~ 2026.12.13 (총 8회차)
주기 : 2주마다 1회
장소 : 오프라인

### 스터디 방식

- 정해진 분량에 대해서 각자 공부 및 정리
- 정리한 내용을 깃허브에 업로드 및 PR 생성
- 정리한 내용을 회차마다 선정된 인원이 발표(당일에 랜덤으로 2-3인 선정)
- 1시간 동안 발표 진행 / 1시간 동안 내용을 바탕으로 질문에 대해서 면접처럼 답변 및 논의

### 스터디 규칙

- 보증금 제도
  - 목적 : 스터디원의 참여의지 독려
  - 금액 : 3만원
- 벌금 제도
  - 목적 : 스터디원의 참여의지 독려, 타 스터디원에게 방해 방지
  - 금액
    - 무단 불참 : 10,000원
    - 무단 지각 : 3,000원
    - 자료 준비 미흡 : 3,000원
